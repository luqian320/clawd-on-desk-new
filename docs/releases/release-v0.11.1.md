# Clawd on Desk v0.11.1

## Personal fork release

- Adds the floating Focus module with activity tracking, configurable daily goals, weekly and all-time summaries, and adjustable Pomodoro sessions.
- Adds persistent modern and pixel Focus HUD skins, with pixel as the default.
- Adds an explicit Quit menu action.
- Mirrors Codex Desktop approval waits through Clawd with a **Go to Codex** action.
- Shows the human-readable approval reason without exposing the full command, and supports modern and pixel notification skins.

## Packages

- macOS Apple Silicon (`arm64`)
- macOS Intel (`x64`)
- Windows x64
- Windows ARM64

Installing v0.11.1 over v0.11.0 replaces the application binary while preserving user data stored in the application data directory.
